Null Ritual

Null Ritual is an interactive, browser-based psychological horror application modeled after an abandoned, compromised mainframe workstation. Built entirely in vanilla web technologies, it blends terminal-driven storytelling with simulated hardware breaches, responsive CSS grid UI, and procedural audio synthesis.

Main Features

Multi-pane surveillance deck design
A responsive two-column grid that separates the interactive command-line interface from an active hardware surveillance panel

Loop-Aware Iteration Persistence
The terminal remembers your previous tries. When you reset the session, it logs your failure iteration count and previous vessel names, which lead to custom narrative entity responses in future runs.

Procedural Sound Synthesis Ambient
Powered by the native **Web Audio API** with real-time dynamic sub-bass oscillators and filtered static noise that shift in pitch and gain intensity as the system corruption progresses.

Infiltration to Hardware Feed
support for immersive hardware capture. The terminal asks for live video and audio access, applying real-time visual distortion filters to simulate entity takeover.

Dynamic Terminal Glitching Mechanics
ghost-typing echoes, text decay timers that consume uncommitted user inputs, title bar manipulation, rapid keystroke panic detection, and a core thermal meltdown countdown sequence.

How to run the program

Download this repository and open index.html in any browser.
